# 世界计划 角色匹配测试 Plugin

基于大五人格模型的 Project Sekai 角色匹配测试插件。通过 39 道题目分析你的五维人格（外向性、宜人性、尽责性、神经质、开放性），匹配最契合的世界计划角色并生成精美的结果图片。

## 功能

- **39 题大五人格测试** — 每题 1-5 分作答，覆盖五个维度
- **20 名角色匹配** — 涵盖 Leo/need、MORE MORE JUMP!、Vivid BAD SQUAD、Wonderlands×Showtime、25时 五大团体
- **结果图片生成** — 含角色立绘（远程加载）、契合度排行、雷达图、维度分析、五维解读
- **会话安全** — 异步锁 + 防连发机制，支持多用户并发独立答题
- **群聊优化** — 10题一批合并发送（合并转发消息），支持连续数字或逗号分隔批量作答，防止刷屏

## 使用

### 私聊模式
1. 发送 `人格测试` 开始答题。
2. 每次收到题目后回复 1-5（1=非常不同意 ~ 5=非常同意）。
3. 答题过程中发送 `0` 可随时退出。

### 群聊模式
1. 发送 `人格测试` 开始答题。
2. 题目将以 **10题一批** 的合并转发消息形式发送。
3. 回复 **10个数字** 进行批量作答，支持连续数字或逗号/空格分隔。例如：
   - 连续数字：`1254324542`
   - 逗号分隔：`1,2,5,4,3,2,4,5,4,2`
4. 答题过程中发送 `0` 可随时退出。

## 指令

| 指令 | 说明 |
|------|------|
| `人格测试` | 开始人格测试 |
| `1` / `2` / `3` / `4` / `5` | 答题（1=非常不同意 ~ 5=非常同意） |
| `0` | 退出测试 |

## 算法

采用**中心化余弦相似度（皮尔逊相关系数）**计算用户与角色的匹配度：
1. **中心化拉伸**：对用户五维平均分进行以 3.0 为中心的 1.5 倍拉伸，放大性格倾向。
2. **余弦相似度**：计算用户性格向量与角色性格向量在减去中立值 3.0 后的夹角余弦值，衡量性格起伏趋势（轮廓）而非绝对分数，消除答题偏好误差。
3. **边界退化**：若用户全选 3（中立），算法自动退化为欧氏距离计算，确保系统稳定。
